# Kotlin 2.4 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the Android/KMM project to Kotlin 2.4.20 and KSP 2.3.12, drop flags and opt-ins for features that are now stable, fix the iOS test compile error, and prove that no new warnings appear in hand-written code.

**Architecture:** All edits are build configuration plus four small source changes. Kotlin versions live in two version catalogs under `android/gradle/`. Compiler flags are set in two buildSrc plugins and three module build scripts. Verification is a full rebuild of every Kotlin compile task compared against the pre-upgrade warning log at `/tmp/kotlin-warnings-before.log`.

**Tech Stack:** Kotlin Multiplatform 2.4.20, KSP 2.3.12, Gradle 9.7.1, AGP 9.3.2, Compose Multiplatform 1.12.0.

## Global Constraints

- All Gradle commands run from `android/` with `--quiet`. Exit code 0 is success regardless of output.
- Kotlin goes to exactly `2.4.20` in both `android/gradle/shared.versions.toml` and `android/gradle/buildSrc.versions.toml`.
- KSP goes to exactly `2.3.12` in both catalogs.
- Gradle, AGP, Compose Multiplatform, Room, and Wire versions stay unchanged.
- Keep `-Xreturn-value-checker=check` and `-Xexpect-actual-classes` everywhere they exist today. Keep every `extraWarnings.set(true)`.
- Generated-source warnings (paths containing `/build/generated/`) and `KLIB resolver` warnings are out of scope and must not be silenced.
- Do not stage `android/gradlew.bat`, any `.DS_Store`, or `android/.idea/yatool.xml`.
- Spec: `docs/superpowers/specs/2026-09-09-kotlin-2.4-upgrade-design.md`.

- [ ] **Step 7b: Pin the Android module name in `shared/integration/base/build.gradle.kts`**

### Task 4: Full verification and warning diff

**Files:**
- No source edits unless Step 3 finds new warnings in hand-written code. Any such fix is applied at the cause in the reported file.

**Interfaces:**
- Consumes: everything from Tasks 1 to 3 and the baseline log `/tmp/kotlin-warnings-before.log`.
- Produces: `/tmp/kotlin-warnings-after.log` and a warning diff showing no new hand-written warnings.

- [ ] **Step 1: Rebuild every Kotlin compile task**

Run:

```bash
./gradlew --quiet --rerun-tasks --continue compileAndroidMain compileAndroidHostTest compileKotlinIosArm64 compileKotlinIosSimulatorArm64 compileTestKotlinIosSimulatorArm64 compileIosMainKotlinMetadata compileCommonMainKotlinMetadata :app:compileDebugKotlin :app:compileReleaseKotlin :app:compileAutotestAndroidTestKotlin :app:compileAutotestUnitTestKotlin :baselineprofile:compileNonMinifiedReleaseKotlin > /tmp/kotlin-warnings-after.log 2>&1; echo "EXIT: $?" >> /tmp/kotlin-warnings-after.log; tail -1 /tmp/kotlin-warnings-after.log
```

Expected: `EXIT: 0`. The baseline exited 1 because of the Task 1 error.

- [ ] **Step 2: Diff hand-written warnings against the baseline**

Run:

```bash
filter() { grep "^w:" "$1" | grep -v "/build/generated/" | grep -vE "KLIB (resolver|loader)" | sed -E 's#^w: file://[^ ]*/android/##' | sort -u; }
filter /tmp/kotlin-warnings-before.log > /tmp/w-before.txt
filter /tmp/kotlin-warnings-after.log > /tmp/w-after.txt
echo "before: $(wc -l < /tmp/w-before.txt)  after: $(wc -l < /tmp/w-after.txt)"
comm -13 /tmp/w-before.txt /tmp/w-after.txt
```

Expected: `before: 0  after: 0` and no lines from `comm`. Any printed line is a new warning.

- [ ] **Step 3: Fix any new warning at its cause**

For each line printed by Step 2, open the file and line it names and fix the code, not the diagnostic. Known Kotlin 2.4 warning shapes and their fixes:

- `Flag '-X...' is no longer needed` in a build script: remove that flag from the `freeCompilerArgs` list it appears in.
- `Annotation target ... default changed` on a constructor property: add the explicit target the message names, for example `@param:` or `@property:`.
- `'...' is deprecated` from the standard library: switch to the replacement named in the message.

Then rerun Step 1 and Step 2 until Step 2 prints nothing.

- [ ] **Step 4: Confirm generated and KLIB warnings did not grow unexpectedly**

Run:

```bash
for f in before after; do echo "$f: generated=$(grep '^w:' /tmp/kotlin-warnings-$f.log | grep -c '/build/generated/') klib=$(grep -cE 'KLIB (resolver|loader)' /tmp/kotlin-warnings-$f.log)"; done
```

Expected: the `after` counts are the same as `before` (generated 494, klib 45) or lower. If the `after` numbers are higher, list the new lines with `comm -13` over the full `^w:` set and report them; do not silence them.
